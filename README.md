하아?

우라-야하! 하아아! 우
푸루야 푸릿 우 야하!!!
하아아?

미이이야하 하아- 하아아 야하!!!!!!!!!!
미이이야하 하아- 우라-야하! 우 하! 푸루야 푸리리릿 우 우 하? 야하!!!

```text
16
81
```

함수를 받아서 두 번 적용하는 프로그램입니다. 첫 줄은 10에 3을 두 번 더하고, 둘째 줄은 그 자리에서 만든 이름 없는 함수로 3을 두 번 제곱합니다.

## 특징

- **우사기의 말로 씁니다.** 숫자는 `야하!!!`, 변수는 `우라`, 함수는 `하아`처럼 모든 키워드가 우사기의 말입니다.
- **함수형입니다.** 함수를 값으로 넘기고, 이름 없는 함수를 만들고, 클로저로 바깥 값을 기억합니다. 부분 적용과 합성으로 함수를 조립하고, 조건도 값을 돌려주는 식으로 씁니다. 한 번 묶은 값은 바뀌지 않습니다.
- **목록과 글을 다룹니다.** 목록 자료형과 map · filter · fold를 처음부터 갖췄고, 글은 글자 목록으로 다룹니다.
- **깊이 제한이 없습니다.** 꼬리 호출은 스택을 쓰지 않아서 10만 번을 돌아도 괜찮습니다.
- **정수 크기 제한 없음.** 20!도 10⁴⁰도 정확하게 계산합니다.
- **런타임 의존성 0.** Node만 있으면 빌드 없이 바로 실행됩니다.
- **브라우저 플레이그라운드.** 설치 없이 웹에서 고치고, 실행하고, 링크로 공유합니다.

## 빠른 시작

Node.js 24 이상이 필요합니다. 저장소의 `.nvmrc`에 버전이 적혀 있어서 `nvm use`로 맞출 수 있습니다.

```bash
node src/cli.ts examples/fibonacci.yaha
```

```bash
echo '야하! 우라~' | node src/cli.ts examples/echo.yaha
```

파일 없이 실행하면 대화형 모드가 됩니다. 코드를 쓰고 빈 줄을 넣으면 실행하고, `:exit`로 끝냅니다. 앞에서 묶은 값과 함수는 계속 기억합니다. 대화형 모드에서 `야푸`는 항상 −1을 돌려줍니다.

```bash
node src/cli.ts
```

`pnpm link --global`을 실행해 두면 어디서든 `ura 파일.yaha`로 실행할 수 있습니다.

## 플레이그라운드

[usagi-lang.github.io/fp-usagi](https://usagi-lang.github.io/fp-usagi/)에서 코드를 고치고 바로 실행할 수 있습니다. `main`에 푸시하면 GitHub Actions가 테스트와 빌드를 거쳐 자동으로 다시 배포합니다.

- 문법 색, 예제 불러오기, 입력(`야푸`), 사전, 숫자·글 인코더를 갖췄습니다.
- `⌘↵`(Windows는 `Ctrl+↵`)로 실행합니다.
- 오류가 나면 편집기에 틀린 말과 줄 번호를 표시하고, **그 자리로 가기**를 누르면 그곳으로 커서를 옮깁니다.
- **공유**를 누르면 코드가 담긴 링크가 만들어집니다.
- 프로그램은 별도 작업 스레드에서 돕니다. 5초가 지나거나 출력이 20만 글자를 넘으면 멈춥니다.

```bash
pnpm web
```

개발 서버를 띄웁니다(`http://localhost:5173`).

```bash
pnpm web:build
```

배포용 정적 파일을 `dist/`에 만듭니다. 배포 워크플로는 [.github/workflows/pages.yml](.github/workflows/pages.yml)에 있습니다.

## 둘러보기

**숫자.** `야하` 뒤에 붙은 `!`의 개수가 숫자입니다. 앞에 `이`를 하나 붙일 때마다 부호가 바뀝니다.

```
미이이야하 야하!!!
미이이야하 이야하!!!
```

→ `3`, `-3`

**변수.** `우`로 시작하고 `우`·`라`·`아`로만 된 말이 변수입니다. 변수는 글자 수로만 구분해서 `우라`, `우아`, `우우`는 모두 같은 변수입니다. `미야아아`로 값을 묶습니다.

```
미야아아 우라 야하!!!!!
미이이야하 우아
```

→ `5`

**계산.** 연산자를 앞에 씁니다. `푸릿`(+), `푸리릿`(−), `푸리리릿`(×), `푸리리리릿`(÷), `푸리리리리릿`(나머지)입니다. `리`가 하나씩 늘어납니다.

```
미이이야하 푸리리릿 야하!!! 푸릿 야하!! 야하!!!!
미이이야하 푸리리리리릿 야하!!!!!!! 야하!!!
```

→ `18`, `1`

**조건.** `푸루`(같다), `푸루루`(작다), `푸루루루`(크다) 뒤에 두 값을 쓰면, 참일 때 그다음 문장 하나나 `하!` … `하?` 블록을 실행합니다. 비교 말을 이어 쓰면 OR가 되어서 `푸루 푸루루`는 "작거나 같다"입니다.

```
푸루 푸루루 야하!! 야하!!! 하!
  미이이야하 야하!
하?
```

→ `1`

**조건식.** 값이 들어갈 자리에 `푸루`를 쓰면 조건식이 됩니다. 비교할 두 값 뒤에 값을 두 개 더 쓰면, 조건이 참일 때 앞의 값이, 거짓일 때 뒤의 값이 됩니다. 고르지 않은 쪽은 계산하지 않습니다. `야하!`(1)와 `야하`(0)를 고르면 참·거짓 값이 됩니다.

```
미이이야하 푸루루 야하!! 야하!!! 야하!!!!!!! 야하!!!!!!!!
미이이야하 푸루 야하!! 야하!!! 야하! 야하
```

→ `7`, `0`

같은 `푸루`라도 문장 맨 앞에 오면 조건문이고, 값 자리에 오면 조건식입니다.

**함수.** `우라-야하!` 다음에 이름(`하아!`, `하아아!` …)과 매개변수를 쓰고, 같은 이름에 `?`를 붙여(`하아?`) 닫습니다. 부를 때는 `하아-`, 값을 돌려줄 때는 `푸루야`를 씁니다. 함수 이름은 `아`의 개수로 구분합니다.

```
우라-야하! 하아! 우
푸루 우 야하 푸루야 야하!
푸루야 푸리리릿 우 하아- 푸리릿 우 야하!
하아?

미이이야하 하아- 야하!!!!!
```

→ `120`

## 함수형 기능

**조건식으로 재귀.** 조건식으로 재귀의 끝을 정하면 함수를 식 하나로 쓸 수 있습니다. 조건식이 고른 호출도 `푸루야` 바로 뒤에 있으면 꼬리 호출이라서 깊이 제한 없이 돕니다. 아래는 유클리드 호제법으로 구한 48과 36의 최대공약수입니다.

```
우라-야하! 하아! 우 우라
푸루야 푸루 우라 야하 우 하아- 우라 푸리리리리릿 우 우라
하아?

미이이야하 하아- 푸리리릿 야하!!!!!! 야하!!!!!!!! 푸리리릿 야하!!!!!! 야하!!!!!!
```

→ `12`

**함수를 값으로.** `-` 없이 `하아`라고만 쓰면 함수 자체를 가리킵니다. 변수에 담은 함수는 `우-`처럼 변수 뒤에 `-`를 붙여 부릅니다. 인자를 몇 개 읽을지는 함수의 매개변수 개수가 정합니다.

**이름 없는 함수.** `우라-야하!` 뒤에 이름 없이 매개변수를 쓰고 `하!` … `하?`로 본문을 감쌉니다. 값이 들어갈 수 있는 곳이면 어디든 쓸 수 있습니다.

**클로저.** 함수는 만들어질 때의 값을 기억합니다. 아래에서 `우`를 나중에 10으로 다시 묶어도, 함수는 만들어질 때의 3을 씁니다.

```
미야아아 우 야하!!!
미야아아 우라 우라-야하! 우우우 하! 푸루야 푸리리릿 우 우우우 하?
미야아아 우 야하!!!!!!!!!!
미이이야하 우라- 야하!!
```

→ `6`

**바뀌지 않는 값.** `미야아아`는 원래 값을 고치지 않고, 같은 이름을 새로 묶어 가립니다. 블록 안에서 묶은 값은 블록이 끝나면 사라집니다.

```
미야아아 우 야하!
푸루 야하 야하 하!
  미야아아 우 야하!!
  미이이야하 우
하?
미이이야하 우
```

→ `2`, `1`

목록 자료형 없이 함수만으로 목록을 만드는 예는 [examples/closure-list.yaha](examples/closure-list.yaha)에 있습니다.

## 목록과 글

**목록.** `우이`는 빈 목록이고, `유후 값 목록`은 목록 앞에 값을 붙인 새 목록입니다. `유후후`는 첫 값을, `유후후후`는 첫 값을 뺀 나머지를 돌려줍니다. 목록도 한 번 만들면 바뀌지 않습니다. `미이이야하`로 출력하면 `[1, 2, 3]`처럼 보여 줍니다.

```
미야아아 우 유후 야하! 유후 야하!! 유후 야하!!! 우이
미이이야하 우
미이이야하 유후후 우
미이이야하 유후후후 우
```

→ `[1, 2, 3]`, `1`, `[2, 3]`

`푸루`는 목록을 담긴 값으로 비교합니다. 그래서 `푸루 목록 우이 …`로 빈 목록인지 보고 재귀를 끝낼 수 있습니다. 아래는 1부터 10까지의 합입니다.

```
우라-야하! 하아! 우 우라
푸루야 푸루 우 우이 우라 하아- 유후후후 우 푸릿 우라 유후후 우
하아?

미이이야하 하아- 유후후후후 야하! 야하!!!!!!!!!! 야하
```

→ `55`

**목록 함수.** 자주 쓰는 함수는 처음부터 들어 있습니다. 함수를 받는 말은 넘긴 함수의 매개변수 개수를 확인합니다.

| 말 | 하는 일 | 다른 언어 |
|---|---|---|
| `유후후후후 A B` | A부터 B까지의 정수 목록 (양 끝 포함) | `[a..b]` |
| `야앗 함수 목록` | 모든 값에 함수를 적용 | `map` |
| `야아앗 함수 목록` | 함수가 0이 아닌 값을 돌려준 것만 남김 | `filter` |
| `야아아앗 함수 처음값 목록` | 왼쪽부터 `함수 누적값 값`으로 접음 | `foldl` |

```
미야아아 우 유후후후후 야하! 야하!!!!!
미이이야하 야앗 우라-야하! 우라 하! 푸루야 푸리리릿 우라 우라 하? 우
미이이야하 야아앗 우라-야하! 우라 하! 푸루야 푸리리리리릿 우라 야하!! 하? 우
미이이야하 야아아앗 우라-야하! 우라 우라라 하! 푸루야 푸릿 우라 우라라 하? 야하 우
```

→ `[1, 4, 9, 16, 25]`, `[1, 3, 5]`, `15`

**글.** 글은 글자 번호(유니코드 코드 포인트)의 목록입니다. `미이이이이야하`는 목록을 글로 한 번에 출력하고, 줄바꿈은 붙이지 않습니다. 목록은 `ura encode`가 대신 만들어 줍니다.

```
미이이이이야하
유후 푸리리릿 야하!!!!!!!! 야하!!!!!!!!!
유후 푸릿 푸리리릿 야하!!!!!!!!!! 야하!!!!!!!!!! 야하!!!!!
유후 야하!!!!!!!!!!
우이
```

→ `Hi`

## 함수 조립

이미 있는 함수로 새 함수를 만드는 말이 세 개 있습니다. 만든 함수도 값이라서 변수에 담거나 목록 함수에 넘길 수 있습니다.

| 말 | 하는 일 | 다른 언어 |
|---|---|---|
| `후응 함수 값` | 첫 매개변수를 값으로 채운 함수 (부분 적용) | Haskell의 `add 3` |
| `후으응 f g` | f를 먼저, g를 나중에 적용하는 함수 (합성) | F#의 `f >> g` |
| `후으으응 값 함수` | 값을 함수에 넘김 (파이프) | Elixir · F#의 `x \|> f` |

**부분 적용.** `후응`은 함수의 첫 매개변수를 채우고, 매개변수가 하나 줄어든 함수를 돌려줍니다. 겹쳐 쓰면 매개변수를 앞에서부터 차례로 채웁니다.

```
우라-야하! 하아! 우 우라
푸루야 푸리리릿 우 우라
하아?

미야아아 우 후응 하아 야하!!!
미이이야하 우- 야하!!!!
미이이야하 야앗 우 유후후후후 야하! 야하!!!!!
```

→ `12`, `[3, 6, 9, 12, 15]`

**합성과 파이프.** `후으응 f g`는 f를 먼저, g를 나중에 적용하는 함수를 만듭니다. 합성한 함수의 매개변수 개수는 f를 따르고, g는 매개변수가 하나여야 합니다. `후으으응 값 함수`는 값을 매개변수가 하나인 함수에 넘깁니다. 이어 쓰면 값이 왼쪽에서 오른쪽으로 함수를 하나씩 지나갑니다.

```
우라-야하! 하아! 우
푸루야 푸릿 우 야하!
하아?

우라-야하! 하아아! 우
푸루야 푸리리릿 우 우
하아아?

미이이야하 야앗 후으응 하아 하아아 유후후후후 야하! 야하!!!!
미이이야하 후으으응 후으으응 야하!!! 하아 하아아
```

→ `[4, 9, 16, 25]`, `16`

`야앗` 같은 목록 말은 함수 값이 아니라서 `후응`에 넘길 수 없습니다. 필요하면 이름 없는 함수로 감싸서 넘깁니다.

## 사전

| 말 | 기능 |
|---|---|
| `야하!!!` | 정수 (`!` 개수) |
| `이` | 부호 바꾸기 (숫자 앞에 붙임) |
| `우`, `우라`, `우라라`, … | 변수 (글자 수로 구분) |
| `미야아아` | 묶기 |
| `미이이야하` | 정수 출력 (뒤에 줄바꿈) |
| `미이이이야하` | 글자 출력 (유니코드 코드 포인트) |
| `미이이이이야하` | 글 출력 (글자 번호 목록) |
| `야푸` | 입력 한 글자 읽기 |
| `푸릿` · `푸리릿` · `푸리리릿` · `푸리리리릿` · `푸리리리리릿` | 더하기 · 빼기 · 곱하기 · 나누기 · 나머지 |
| `푸루` · `푸루루` · `푸루루루` | 같다 · 작다 · 크다 (문장 맨 앞에서는 조건문) |

## 명세

### 문장

프로그램, 함수 본문, 블록은 문장을 위에서부터 차례로 실행합니다.

| 문장 | 형태 |
|---|---|
| 출력 | `미이이야하 식`, `미이이이야하 식`, `미이이이이야하 식` |
| 묶기 | `미야아아 변수 식` |
| 조건 | `비교… 식 식` 다음에 문장 하나 또는 블록 |
| 돌려주기 | `푸루야 식` 또는 `푸루야`. 식은 `푸루야`와 같은 줄에서 시작합니다 |
| 호출 · 계산 | `하아- …`, `우- …`, `푸릿 …` 등. 결과는 버립니다 |
| 블록 | `하! 문장… 하?` |
| 함수 선언 | `우라-야하! 하아! 변수… 문장… 하아?` |

### 식

| 식 | 형태 |
|---|---|
| 정수 | `이…야하!…` |
| 변수 | `우…` |
| 계산 | `푸릿 식 식` 등 |
| 조건식 | `비교… 식 식 식 식` |
| 호출 | `하아- 식…`, `우- 식…` (식 개수 = 매개변수 개수) |
| 함수 값 | `하아` |
| 이름 없는 함수 | `우라-야하! 변수… 하! 문장… 하?` |
| 입력 | `야푸` |
| 빈 목록 | `우이` |
| 목록 | `유후 식 식`, `유후후 식`, `유후후후 식`, `유후후후후 식 식` |
| 목록 함수 | `야앗 식 식`, `야아앗 식 식`, `야아아앗 식 식 식` |
| 함수 조립 | `후응 식 식`, `후으응 식 식`, `후으으응 식 식` |

### 평가 규칙

| 항목 | 규칙 |
|---|---|
| 값 | 정수(크기 제한 없음), 함수, 목록 |
| 조건식 | 앞의 두 식을 비교해서 참이면 셋째 식, 거짓이면 넷째 식의 값이 됩니다. 고르지 않은 식은 계산하지 않습니다 |
| 비교 | `푸루`는 정수는 값을, 목록은 담긴 값을 차례로 비교하고, 함수는 같은 함수일 때만 같습니다. 종류가 다르면 다릅니다. `푸루루`·`푸루루루`는 정수만 비교합니다 |
| 참·거짓 | 따로 없습니다. 보통 1과 0을 조건식으로 골라서 씁니다 |
| 묶기 범위 | `미야아아`로 묶은 값은 그 블록의 나머지 부분에서만 보입니다 |
| 묶지 않은 변수 | 0 |
| 함수 이름 | 선언한 블록 안이면 선언보다 앞에서도 부를 수 있습니다. 같은 블록에 같은 이름을 두 번 선언하면 오류입니다 |
| 함수 환경 | 이름 있는 함수는 블록이 시작될 때의 값을, 이름 없는 함수는 만들어진 자리의 값을 기억합니다 |
| 돌려주기 | `푸루야`가 없거나, 같은 줄에서 뒤에 식이 시작하지 않으면 0 |
| 나눗셈 | 0 쪽으로 버립니다. `-7 ÷ 2 = -3`이고, 나머지는 나뉘는 수의 부호를 따라서 `-7 % 2 = -1`입니다 |
| 꼬리 호출 | `푸루야` 바로 뒤의 호출과 `후으으응`, 그 자리의 조건식이 고른 호출은 스택을 쓰지 않습니다 |
| 출력 | `미이이야하`는 값 뒤에 줄바꿈을 붙입니다. 함수는 이름을, 목록은 `[1, 2, 3]`처럼 출력합니다. `미이이이야하`와 `미이이이이야하`는 줄바꿈을 붙이지 않습니다 |
| 목록 | `유후`의 둘째 값은 목록이어야 합니다. 빈 목록에 `유후후`나 `유후후후`를 쓰면 오류입니다 |
| 목록 함수 | `야앗`·`야아앗`은 매개변수가 1개, `야아아앗`은 2개인 함수를 받습니다. `야아앗`의 함수는 정수를 돌려줘야 합니다 |
| 함수 조립 | `후응`은 매개변수가 1개 이상인 함수를 받습니다. `후으응`의 뒤 함수와 `후으으응`의 함수는 매개변수가 1개여야 합니다. 부분 적용한 함수는 원래 함수의 이름으로, 합성한 함수는 `후으응`으로 출력됩니다 |
| 입력 | `야푸`는 코드 포인트를 돌려주고, 입력이 끝나면 −1 |

### 오류

오류 메시지는 `하아? 하아?`로 시작하고, 위치를 함께 알려 줍니다.

```text
하아? 하아? (2줄 7칸) '안녕'... 우사기는 그런 말 안 해
하아? 하아? (2줄 7칸) '우-'... 함수가 아니라서 부를 수 없어
하아? 하아? (3줄 1칸) '하아?'(으)로 닫아야 하는데 '하아아?'가 나왔어
```

## 도구

`야하!!!!!!!!…`를 손으로 세기는 어렵습니다. 인코더가 대신 세어 줍니다.

```bash
node src/cli.ts num 72
```

72를 `푸리리릿 야하!!!!!!!! 야하!!!!!!!!!`(8 × 9)로 바꿔 줍니다. 큰 수는 a × b + r로 쪼개서 짧게 만듭니다.

```bash
printf '우라!\n' | node src/cli.ts encode
```

주어진 글을 출력하는 프로그램을 통째로 만들어 줍니다. 글은 `유후 …` 목록이 되므로, 그 부분만 떼어 프로그램 안의 글로 써도 됩니다.
