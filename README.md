```
푸루야 우- 우- 우라
하아?

우라-야하! 하아아! 우
푸루야 푸릿 우 야하!!!
하아아?

미이이야하 하아- 하아아 야하!!!!!!!!!!
미이이야하 하아- 우라-야하! 우 하! 푸루야 푸리리릿 우 우 하? 야하!!!
```

```text
16

```

함수를 인자로 받아 두 번 적용하는 프로그램입니다. 출력의 첫 줄은 10에 3을 두 번 더한 값이고, 둘째 줄은 그 자리에서 만든 익명 함수로 3을 두 번 제곱한 값입니다.

## 특징

- **우사기의 말로 씁니다.** 숫자는 `야하!!!`, 변수는 `우라`, 함수는 `하아`처럼 모든 키워드가 우사기의 말입니다.
- **함수형입니다.** 함수를 값으로 넘기고, 익명 함수를 만들고, 클로저로 바깥 변수를 캡처합니다. 부분 적용과 합성으로 함수를 조합하고, `푸릿` 같은 키워드도 그대로 함수 값으로 넘깁니다. 조건 분기도 표현식(조건식)으로 쓸 수 있습니다. 한 번 바인딩한 값은 바뀌지 않습니다.
- **리스트와 문자열을 다룹니다.** 리스트 자료형과 map · filter · fold, length · reverse · sortBy · find 같은 리스트 함수가 내장되어 있고, 구조 분해로 리스트를 첫 원소와 나머지로 나눌 수 있습니다. 문자열은 코드 포인트의 리스트로 다룹니다.
- **꼬리 호출은 깊이 제한이 없습니다.** 꼬리 호출은 스택을 쓰지 않아서 10만 번 재귀해도 괜찮습니다. 꼬리 호출이 아닌 재귀는 `ura`에서 약 25만 단계, 플레이그라운드에서 수백 단계까지 가능합니다.
- **임의 정밀도 정수.** 20!도 10⁴⁰도 정확하게 계산합니다.
- **런타임 의존성 0.** Node만 있으면 빌드 없이 바로 실행됩니다.
- **브라우저 플레이그라운드.** 설치 없이 웹에서 코드를 편집하고, 실행하고, 링크로 공유합니다.

## 빠른 시작

Node.js 24 이상이 필요합니다. 저장소의 `.nvmrc`에 버전이 지정되어 있어서 `nvm use`로 맞출 수 있습니다.

```bash
node src/cli.ts examples/fibonacci.yaha
```

```bash
echo '야하! 우라~' | node src/cli.ts examples/echo.yaha
```

`ura`는 스택을 크게 잡은 워커 스레드에서 프로그램을 실행하므로, 꼬리 호출이 아닌 재귀도 약 25만 단계까지 가능합니다.

파일 없이 실행하면 REPL(대화형 모드)이 시작됩니다. 코드를 입력하고 빈 줄을 넣으면 실행되고, `:exit`로 종료합니다. 앞에서 바인딩한 값과 선언한 함수는 계속 유지됩니다. REPL에서 `야푸`는 항상 −1을 반환합니다.

```bash
node src/cli.ts
```

`pnpm link --global`을 실행해 두면 어디서든 `ura 파일.yaha`로 실행할 수 있습니다.

## 플레이그라운드

[usagi-lang.github.io/fp-usagi](https://usagi-lang.github.io/fp-usagi/)에서 코드를 편집하고 바로 실행할 수 있습니다. `main`에 푸시하면 GitHub Actions가 테스트와 빌드를 거쳐 자동으로 다시 배포합니다.

- 문법 강조, 예제 불러오기, 입력(`야푸`), 사전, 숫자·문자열 인코더를 제공합니다.
- `⌘↵`(Windows는 `Ctrl+↵`)로 실행합니다.
- 오류가 나면 편집기에 오류 위치를 줄 번호와 함께 표시하고, **그 자리로 가기**를 누르면 그 위치로 커서를 옮깁니다. 경고는 노란색으로 표시합니다.
- **공유**를 누르면 코드가 담긴 링크가 만들어집니다.
- 프로그램은 별도의 웹 워커에서 실행됩니다. 5초가 지나거나 출력이 20만 자를 넘으면 중단합니다.

```bash
pnpm web
```

개발 서버를 띄웁니다(`http://localhost:5173`).

```bash
pnpm web:build
```

배포용 정적 파일을 `dist/`에 생성합니다. 배포 워크플로는 [.github/workflows/pages.yml](.github/workflows/pages.yml)에 있습니다.

## 둘러보기

**숫자.** `야하` 뒤에 붙은 `!`의 개수가 숫자입니다. 앞에 `이`를 하나 붙일 때마다 부호가 바뀝니다.

```
미이이야하 야하!!!
미이이야하 이야하!!!
```

→ `3`, `-3`

**변수.** `우`로 시작하고 `우`·`라`·`아`로만 이루어진 단어가 변수입니다. 변수는 글자 수로만 구분하므로 `우라`, `우아`, `우우`는 모두 같은 변수입니다. `미야아아`로 값을 바인딩합니다.

```
미야아아 우라 야하!!!!!
미이이야하 우아
```

→ `5`

**산술 연산.** 연산자를 피연산자 앞에 씁니다(전위 표기). `푸릿`(+), `푸리릿`(−), `푸리리릿`(×), `푸리리리릿`(÷), `푸리리리리릿`(나머지)입니다. `리`가 하나씩 늘어납니다.

```
미이이야하 푸리리릿 야하!!! 푸릿 야하!! 야하!!!!
미이이야하 푸리리리리릿 야하!!!!!!! 야하!!!
```

→ `18`, `1`

**조건문.** `푸루`(같다), `푸루루`(작다), `푸루루루`(크다) 뒤에 두 값을 쓰면, 참일 때 바로 다음 문 하나나 `하!` … `하?` 블록을 실행합니다. 비교 연산자를 이어 쓰면 OR로 결합되어 `푸루 푸루루`는 "작거나 같다"가 됩니다.

```
푸루 푸루루 야하!! 야하!!! 하!
  미이이야하 야하!
하?
```

→ `1`

**조건식.** 값이 들어갈 자리에 `푸루`를 쓰면 조건식이 됩니다. 비교할 두 값 뒤에 값을 두 개 더 쓰면, 조건이 참일 때 앞의 값이, 거짓일 때 뒤의 값이 결과가 됩니다. 선택되지 않은 쪽은 평가하지 않습니다. 결과로 `야하!`(1)와 `야하`(0)를 쓰면 참·거짓 값을 얻습니다.

```
미이이야하 푸루루 야하!! 야하!!! 야하!!!!!!! 야하!!!!!!!!
미이이야하 푸루 야하!! 야하!!! 야하! 야하
```

→ `7`, `0`

같은 `푸루`라도 문의 맨 앞에 오면 조건문이고, 값 자리에 오면 조건식입니다.

**함수.** `우라-야하!` 다음에 이름(`하아!`, `하아아!` …)과 매개변수를 쓰고, 같은 이름에 `?`를 붙여(`하아?`) 닫습니다. 호출할 때는 `하아-`, 값을 반환할 때는 `푸루야`를 씁니다. 함수 이름은 `아`의 개수로 구분합니다.

```
우라-야하! 하아! 우
푸루 우 야하 푸루야 야하!
푸루야 푸리리릿 우 하아- 푸리릿 우 야하!
하아?

미이이야하 하아- 야하!!!!!
```

→ `120`

## 함수형 기능

**조건식으로 재귀.** 조건식으로 재귀의 종료 조건을 정하면 함수 본문을 표현식 하나로 쓸 수 있습니다. 조건식이 선택한 호출도 `푸루야` 바로 뒤에 있으면 꼬리 호출이므로 깊이 제한 없이 실행됩니다. 아래는 유클리드 호제법으로 구한 48과 36의 최대공약수입니다.

```
우라-야하! 하아! 우 우라
푸루야 푸루 우라 야하 우 하아- 우라 푸리리리리릿 우 우라
하아?

미이이야하 하아- 푸리리릿 야하!!!!!! 야하!!!!!!!! 푸리리릿 야하!!!!!! 야하!!!!!!
```

→ `12`

**함수를 값으로.** `-` 없이 `하아`라고만 쓰면 함수 자체를 가리킵니다. 변수에 담은 함수는 `우-`처럼 변수 뒤에 `-`를 붙여 호출합니다. 인자를 몇 개 읽을지는 함수의 매개변수 개수로 정해집니다.

**익명 함수.** `우라-야하!` 뒤에 이름 없이 매개변수를 쓰고 `하!` … `하?`로 본문을 감쌉니다. 값이 들어갈 수 있는 곳이면 어디든 쓸 수 있습니다.

**클로저.** 함수는 생성될 때의 환경을 캡처합니다. 아래에서 나중에 `우`를 10으로 다시 바인딩해도, 함수는 생성될 때의 값인 3을 씁니다.

```
미야아아 우 야하!!!
미야아아 우라 우라-야하! 우우우 하! 푸루야 푸리리릿 우 우우우 하?
미야아아 우 야하!!!!!!!!!!
미이이야하 우라- 야하!!
```

→ `6`

**불변 값.** `미야아아`는 기존 값을 수정하지 않고, 같은 이름에 새 값을 바인딩해 이전 값을 가립니다(섀도잉). 블록 안에서 바인딩한 값은 블록이 끝나면 사라집니다.

```
미야아아 우 야하!
푸루 야하 야하 하!
  미야아아 우 야하!!
  미이이야하 우
하?
미이이야하 우
```

→ `2`, `1`

리스트 자료형 없이 함수만으로 리스트를 만드는 예제는 [examples/closure-list.yaha](examples/closure-list.yaha)에 있습니다.

## 리스트와 문자열

**리스트.** `우이`는 빈 리스트이고, `유후 값 리스트`는 리스트 앞에 값을 붙인 새 리스트입니다(cons). `유후후`는 첫 원소를, `유후후후`는 첫 원소를 뺀 나머지를 반환합니다. 리스트도 한 번 만들면 바뀌지 않습니다. `미이이야하`로 출력하면 `[1, 2, 3]`처럼 표시됩니다.

```
미야아아 우 유후 야하! 유후 야하!! 유후 야하!!! 우이
미이이야하 우
미이이야하 유후후 우
미이이야하 유후후후 우
```

→ `[1, 2, 3]`, `1`, `[2, 3]`

`푸루`는 리스트를 원소 단위로 비교합니다. 그래서 `푸루 리스트 우이 …`로 빈 리스트인지 확인해 재귀를 끝낼 수 있습니다. 아래는 1부터 10까지의 합입니다.

```
우라-야하! 하아! 우 우라
푸루야 푸루 우 우이 우라 하아- 유후후후 우 푸릿 우라 유후후 우
하아?

미이이야하 하아- 유후후후후 야하! 야하!!!!!!!!!! 야하
```

→ `55`

**구조 분해.** `미야아아` 다음에 변수 대신 `유후 패턴 패턴`을 쓰면, 리스트의 첫 원소는 앞 패턴에, 나머지는 뒤 패턴에 한 번에 바인딩합니다. 패턴 자리에 `유후`를 다시 쓰면 앞에서부터 원소를 여러 개 꺼낼 수 있습니다. 빈 리스트나 리스트가 아닌 값은 구조 분해할 수 없어서 오류가 납니다.

```
미야아아 유후 우 유후 우라 우라라 유후후후후 야하! 야하!!!!!
미이이야하 우
미이이야하 우라
미이이야하 우라라
```

→ `1`, `2`, `[3, 4, 5]`

`유후후`와 `유후후후`를 여러 번 쓰는 대신 한 번 구조 분해해서 변수로 씁니다. 구조 분해로 작성한 삽입 정렬이 [examples/sort.yaha](examples/sort.yaha)에 있습니다.

**리스트 함수.** 자주 쓰는 리스트 함수가 내장되어 있습니다. 함수를 인자로 받는 고차 함수는 넘긴 함수의 매개변수 개수를 검사합니다.

| 키워드 | 동작 | 다른 언어 |
|---|---|---|
| `유후후후후 A B` | A부터 B까지의 정수 리스트 (양 끝 포함) | `[a..b]` |
| `유후후후후후 리스트` | 원소 개수 | `length` |
| `유후후후후후후 리스트` | 원소를 역순으로 담은 리스트 | `reverse` |
| `유후후후후후후후 리스트 리스트` | 두 리스트를 연결한 리스트 | `++`, `append` |
| `유후후후후후후후후 N 리스트` | 앞에서 N개 | `take` |
| `유후후후후후후후후후 N 리스트` | 앞에서 N개를 제외한 나머지 | `drop` |
| `유후후후후후후후후후후 리스트 리스트` | 같은 위치의 원소끼리 `[앞, 뒤]` 쌍으로 묶은 리스트 | `zip` |
| `야앗 함수 리스트` | 모든 원소에 함수를 적용 | `map` |
| `야아앗 함수 리스트` | 함수가 0이 아닌 값을 반환한 원소만 남김 | `filter` |
| `야아아앗 함수 초깃값 리스트` | 왼쪽부터 `함수 누적값 원소`로 접음 | `foldl` |
| `야아아아앗 함수 리스트` | 원소마다 함수가 반환한 리스트를 모두 이어 붙임 | `flatMap`, `concatMap` |
| `야아아아아앗 함수 리스트` | 함수가 0이 아닌 값을 반환하는 원소가 하나라도 있으면 1, 없으면 0 | `any` |
| `야아아아아아앗 함수 리스트` | 모든 원소에서 함수가 0이 아닌 값을 반환하면 1, 아니면 0 | `all` |
| `야아아아아아아앗 함수 리스트` | 함수가 0이 아닌 값을 반환한 첫 원소 하나만 담은 리스트, 없으면 `우이` | `find` |
| `야아아아아아아아앗 함수 리스트` | 함수가 1을 반환하면 앞 원소가 먼저 오도록 정렬 | `sortBy` |

```
미야아아 우 유후후후후 야하! 야하!!!!!
미이이야하 야앗 우라-야하! 우라 하! 푸루야 푸리리릿 우라 우라 하? 우
```

- `sortBy`에 넘기는 비교 함수는 매개변수가 2개이고, 앞 원소가 먼저 와야 하면 1, 아니면 0을 반환합니다. `이 푸루루`는 오름차순, `이 푸루루루`는 내림차순입니다. 1이나 0이 아닌 값을 반환하면 오류가 납니다. 두 값의 차를 반환하는 `이 푸리릿` 같은 비교 함수가 오류 없이 잘못된 순서를 내놓지 않도록 막기 위해서입니다. 안정 정렬이라서 같은 값끼리는 원래 순서를 유지합니다.
- `find`는 없을 수도 있는 값을 빈 리스트나 원소 하나짜리 리스트로 반환합니다. `푸루 결과 우이 …`로 찾았는지 확인하고, `미야아아 유후 우 우라 결과`로 구조 분해해서 꺼냅니다.
- `any` · `all` · `find`는 `야아앗`처럼 0이 아닌 값을 참으로 보고, 단락 평가를 하므로 결과가 정해지면 남은 원소에는 함수를 호출하지 않습니다.
- `take`와 `drop`은 리스트가 N개보다 짧으면 있는 만큼만 처리합니다. N이 음수면 오류입니다. `zip`은 짧은 리스트가 끝나는 곳에서 멈춥니다.
- 이 키워드들은 인터프리터 내부에서 반복문으로 처리하므로, 리스트가 길어도 재귀 깊이 제한에 걸리지 않습니다.

## 함수 조합

기존 함수로 새 함수를 만드는 키워드가 네 개 있습니다. 만든 함수도 값이므로 변수에 담거나 리스트 함수에 넘길 수 있습니다.

| 키워드 | 동작 | 다른 언어 |
|---|---|---|
| `후응 함수 값` | 첫 매개변수를 값으로 채운 함수 (부분 적용) | Haskell의 `add 3` |
| `후으응 f g` | f를 먼저, g를 나중에 적용하는 함수 (합성) | F#의 `f >> g` |
| `후으으응 값 함수` | 값을 함수에 넘김 (파이프) | Elixir · F#의 `x \|> f` |
| `후으으으응 함수` | 앞의 두 매개변수 순서를 바꾼 함수 (flip) | Haskell의 `flip` |

**부분 적용.** `후응`은 함수의 첫 매개변수를 채우고, 매개변수가 하나 줄어든 함수를 반환합니다. 중첩해서 쓰면 앞에서부터 차례로 매개변수를 채웁니다.

```
우라-야하! 하아! 우 우라
푸루야 푸리리릿 우 우라
하아?

미야아아 우 후응 하아 야하!!!
미이이야하 우- 야하!!!!
미이이야하 야앗 우 유후후후후 야하! 야하!!!!!
```

→ `12`, `[3, 6, 9, 12, 15]`

**합성과 파이프.** `후으응 f g`는 f를 먼저, g를 나중에 적용하는 함수를 만듭니다. 합성한 함수의 매개변수 개수는 f를 따르고, g는 매개변수가 하나여야 합니다. `후으으응 값 함수`는 값을 매개변수가 하나인 함수에 넘깁니다. 연달아 쓰면 값이 왼쪽에서 오른쪽으로 함수를 하나씩 통과합니다.

```
우라-야하! 하아! 우
푸루야 푸릿 우 야하!
하아?

우라-야하! 하아아! 우
푸루야 푸리리릿 우 우
하아아?

미이이야하 야앗 후으응 하아 하아아 유후후후후 야하! 야하!!!!
미이이야하 후으으응 후으으응 야하!!! 하아 하아아
```

→ `[4, 9, 16, 25]`, `16`

**flip.** `후으으으응 함수`는 첫째와 둘째 매개변수의 순서를 바꾼 함수를 만듭니다. 매개변수가 2개 이상인 함수만 받고, 셋째 매개변수부터는 그대로 둡니다. flip한 함수를 출력하면 `후으으으응`으로 표시됩니다.

```
미이이야하 야아아앗 후으으으응 이 유후 우이 유후후후후 야하! 야하!!!!
미야아아 우 후으으으응 이 푸리릿
미이이야하 야앗 후응 우 야하! 유후후후후 야하!!!! 야하!!!!!!
```

→ `[4, 3, 2, 1]`, `[3, 4, 5]`

- `야아아앗`은 `함수 누적값 원소` 순서로 호출하고 `유후`는 `값 리스트` 순서로 인자를 받으므로, flip한 `유후`를 넘기면 리스트를 뒤집는 fold가 됩니다.
- `후응`은 첫 매개변수만 채웁니다. 둘째 줄의 `우`는 빼는 수를 먼저 받는 뺄셈 함수라서, `후응 우 야하!`는 1을 빼는 함수입니다.

**키워드를 함수 값으로.** 띄어 쓴 `이` 다음에 인자를 받는 키워드를 쓰면, 그 키워드가 함수 값이 됩니다. `이`는 원래 "이거 봐봐"라는 뜻입니다. 매개변수 개수는 그 키워드가 받는 인자 개수와 같아서 `이 푸릿`은 2개, `이 유후후`는 1개, `이 야아아앗`은 3개입니다. 산술 연산자 · 비교 연산자 · 리스트 키워드 · 리스트 함수 · 함수 조합 키워드를 모두 쓸 수 있습니다.

```
미이이야하 야아아앗 이 푸릿 야하 유후후후후 야하! 야하!!!!!!!!!!
미이이야하 야아아앗 이 푸리리릿 야하! 유후후후후 야하! 야하!!!!!
미이이야하 야아앗 후응 이 푸루루 야하!!! 유후후후후 야하! 야하!!!!!!
미이이야하 후으으응 유후후후후 야하! 야하!!! 후응 이 야앗 후응 이 푸리리릿 야하!!
```

→ `55`, `120`, `[4, 5, 6]`, `[2, 4, 6]`

- 첫 줄은 1부터 10까지의 합, 둘째 줄은 5!입니다.
- 비교 연산자는 참이면 1, 거짓이면 0을 반환합니다. `후응 이 푸루루 야하!!!`는 "3이 인자보다 작다"라는 함수라서 3보다 큰 원소만 남깁니다. 비교 연산자를 이어 쓰면 OR로 결합되어 `이 푸루 푸루루`는 "작거나 같다"가 됩니다.
- 마지막 줄은 `야앗`에 2를 곱하는 함수를 부분 적용한 다음, 그 함수에 리스트를 파이프로 넘깁니다.
- 숫자 앞에 붙여 쓴 `이`(`이야하!`)는 지금까지처럼 부호를 바꿉니다.

### 평가 규칙

| 항목 | 규칙 |
|---|---|
| 값 | 정수(임의 정밀도), 함수, 리스트 |
| 조건식 | 앞의 두 표현식을 비교해서 참이면 셋째 표현식, 거짓이면 넷째 표현식의 값이 됩니다. 선택되지 않은 분기는 평가하지 않습니다 |
| 비교 | `푸루`는 정수는 값으로, 리스트는 원소를 차례로 비교하고, 함수는 같은 함수일 때만 같습니다. 타입이 다르면 다릅니다. `푸루루`·`푸루루루`는 정수만 비교합니다 |
| 참·거짓 | 불리언 타입은 따로 없습니다. 보통 조건식으로 1과 0 중 하나를 골라 씁니다 |
| 스코프 | `미야아아`로 바인딩한 값은 그 블록의 나머지 부분에서만 보입니다 |
| 구조 분해 | `유후` 패턴에는 빈 리스트가 아닌 리스트가 와야 합니다. 첫 원소는 앞 패턴에, 나머지는 뒤 패턴에 바인딩합니다. 한 번에 바인딩하는 변수끼리 글자 수가 같으면 오류입니다 |
| 정의되지 않은 변수 | 오류입니다. 선택되지 않은 조건식 분기처럼 평가하지 않는 자리에서는 괜찮습니다 |
| 함수 이름 | 선언한 블록 안이면 선언보다 앞에서도 호출할 수 있습니다(호이스팅). 같은 블록에 같은 이름을 두 번 선언하면 오류입니다 |
| 함수 환경 | 이름 있는 함수는 선언 위치까지 바인딩된 값을, 익명 함수는 생성된 위치의 값을 캡처합니다. 이름 있는 함수를 선언보다 앞에서 호출하면 블록이 시작될 때까지 바인딩된 값만 봅니다 |
| 반환 | `푸루야`가 없거나, 같은 줄에서 뒤에 표현식이 시작하지 않으면 0 |
| 나눗셈 | 몫은 0 방향으로 버립니다. `-7 ÷ 2 = -3`이고, 나머지는 피제수의 부호를 따라서 `-7 % 2 = -1`입니다 |
| 꼬리 호출 | `푸루야` 바로 뒤의 호출과 `후으으응`, 그 위치의 조건식이 선택한 호출은 스택을 쓰지 않습니다. 다른 호출은 스택을 쓰므로, `ura`에서 약 25만 단계, 플레이그라운드에서 수백 단계를 넘으면 해당 호출 위치를 가리키며 멈춥니다 |
| 출력 | `미이이야하`는 값 뒤에 줄바꿈을 붙입니다. 함수는 이름을, 리스트는 `[1, 2, 3]`처럼 출력합니다. `미이이이야하`와 `미이이이이야하`는 줄바꿈을 붙이지 않습니다 |
| 리스트 | `유후`의 둘째 인자는 리스트여야 합니다. 빈 리스트에 `유후후`나 `유후후후`를 쓰면 오류입니다. `take`와 `drop`의 N은 0 이상의 정수이고, 리스트가 짧으면 있는 만큼만 처리합니다. `zip`은 짧은 리스트에서 멈춥니다 |
| 리스트 함수 | `야아아앗`과 `sortBy`는 매개변수가 2개, 나머지는 1개인 함수를 받습니다. `야아앗` · `any` · `all` · `find`의 함수는 정수를 반환하고, 0이 아니면 참입니다. `야아아아앗`의 함수는 리스트를, `sortBy`의 함수는 1이나 0을 반환해야 합니다. `sortBy`는 안정 정렬입니다. 리스트 함수는 인터프리터 내부에서 반복문으로 처리하므로 재귀 깊이 제한이 없습니다 |
| 함수 조합 | `후응`은 매개변수가 1개 이상, `후으으으응`은 2개 이상인 함수를 받습니다. `후으응`의 뒤 함수와 `후으으응`의 함수는 매개변수가 1개여야 합니다. 부분 적용한 함수는 원래 함수의 이름으로, 합성한 함수는 `후으응`으로, flip한 함수는 `후으으으응`으로 출력됩니다 |
| 키워드를 함수 값으로 | `이 키워드`의 매개변수 개수는 그 키워드가 받는 인자 개수입니다. 인자를 받지 않는 `야푸`·`우이`와 출력 키워드는 쓸 수 없습니다. 비교 연산자는 1이나 0을 반환합니다. 출력하면 키워드 이름이 나오고, 같은 키워드에 같은 값을 채운 함수끼리는 `푸루`로 비교하면 같습니다 |
| 입력 | `야푸`는 코드 포인트를 반환하고, 입력이 끝나면 −1 |
| 인자 줄바꿈 | 함수를 호출할 때 인자가 다음 줄 맨 앞에서 시작하고, 그 줄이 호출한 줄보다 더 들여 쓰여 있지 않으면 경고합니다. 경고는 실행을 멈추지 않고, 한 호출 위치에 한 번만 나옵니다 |
| 미사용 값 | 산술 연산자 · 리스트 키워드 · 함수 조합 키워드가 문의 맨 앞에 오면 결과가 버려지므로 경고합니다. 함수를 호출하는 `야앗` 계열 키워드와 `후으으응`, 입력 `야푸`는 경고하지 않습니다. 경고는 실행을 멈추지 않고, 한 위치에 한 번만 나옵니다 |

### 오류

오류 메시지는 `하아? 하아?`로 시작하고, 오류 위치를 함께 알려 줍니다.

```text
하아? 하아? (2줄 7칸) '안녕'... 우사기는 그런 말 안 해
하아? 하아? (2줄 12칸) '우라'... 글자 수가 2인 변수는 정의되지 않았어
하아? 하아? (2줄 7칸) '우-'... 함수가 아니라서 호출할 수 없어
하아? 하아? (3줄 7칸) '하아-'에 넘길 인자가 모자라. 매개변수는 2개인데 1개만 있어
하아? 하아? (2줄 7칸) '야아아아아아아아앗'에 넘긴 함수는 1이나 0을 반환해야 하는데 -2가 나왔어
하아? 하아? (3줄 1칸) '하아?'(으)로 닫아야 하는데 '하아아?'가 나왔어
```

실수일 가능성이 큰 코드는 `하아?` 하나로 시작하는 경고로 알려 줍니다. 경고가 나도 실행은 계속됩니다. `ura`는 경고를 표준 오류(stderr)로 출력하고, 플레이그라운드는 출력 창과 편집기에 노란색으로 표시합니다.

```text
하아? (5줄 1칸) '하아-'가 6줄의 '하아-'까지 인자로 가져갔어. 인자를 빠뜨린 게 아니라면 6줄을 더 들여 써
하아? (3줄 1칸) '유후' 결과를 아무도 안 써. 반환하려면 앞에 '푸루야'를, 출력하려면 '미이이야하'를 붙여
```

인자를 일부러 다음 줄에 이어 쓸 때는 그 줄을 더 들여 쓰면 경고가 나지 않습니다. 둘째 경고는 값을 반환할 줄에 `푸루야`를 빠뜨렸을 때 나옵니다. 그 값은 버려지고 함수는 0을 반환하기 때문에, 그대로 두면 엉뚱한 곳에서 오류가 납니다.

## 도구

`야하!!!!!!!!…`를 손으로 세기는 어렵습니다. 인코더가 대신 세어 줍니다.

```bash
node src/cli.ts num 72
```

72를 `푸리리릿 야하!!!!!!!! 야하!!!!!!!!!`(8 × 9)로 바꿔 줍니다. 큰 수는 a × b + r 꼴로 나눠서 짧은 표현식을 만듭니다.

```bash
printf '우라!\n' | node src/cli.ts encode
```

주어진 문자열을 출력하는 프로그램 전체를 만들어 줍니다. 문자열은 `ura encode '우라!'`처럼 인자로 넘겨도 되고, 인자가 없으면 표준 입력에서 읽습니다. 문자열은 `유후 …` 리스트로 바뀌므로, 그 부분만 떼어 다른 프로그램에서 문자열 값으로 써도 됩니다.

```mermaid
  A[".yaha 소스"] -->|lexer| B["토큰"] -->|parser| C["블록 · 함수 구조"] -->|interpreter| D["출력"]
```

```text
├── src/
│   ├── language.ts      키워드 표
```
