```
우라-야하! 하아! 우 우라
푸루야 우- 우- 우라
하아?

우라-야하! 하아아! 우
푸루야 푸릿 우 야하!!!
하아아?

미이이야하 하아- 하아아 야하!!!!!!!!!!
미이이야하 하아- 우라-야하! 우 하! 푸루야 푸리리릿 우 우 하? 야하!!!
```

```text
16
81
```

함수를 받아서 두 번 적용하는 프로그램입니다. 첫 줄은 10에 3을 두 번 더하고, 둘째 줄은 그 자리에서 만든 이름 없는 함수로 3을 두 번 제곱합니다.

## 특징

- **우사기의 말로 씁니다.** 숫자는 `야하!!!`, 변수는 `우라`, 함수는 `하아`처럼 모든 키워드가 우사기의 말입니다.
- **함수형입니다.** 함수를 값으로 넘기고, 이름 없는 함수를 만들고, 클로저로 바깥 값을 기억합니다. 한 번 묶은 값은 바뀌지 않습니다.
- **깊이 제한이 없습니다.** 꼬리 호출은 스택을 쓰지 않아서 10만 번을 돌아도 괜찮습니다.
- **정수 크기 제한 없음.** 20!도 10⁴⁰도 정확하게 계산합니다.
- **런타임 의존성 0.** Node만 있으면 빌드 없이 바로 실행됩니다.
- **브라우저 플레이그라운드.** 설치 없이 웹에서 고치고, 실행하고, 링크로 공유합니다.

## 빠른 시작

Node.js 24 이상이 필요합니다. 저장소의 `.nvmrc`에 버전이 적혀 있어서 `nvm use`로 맞출 수 있습니다.

```bash
node src/cli.ts examples/fibonacci.yaha
```

```bash
echo '야하! 우라~' | node src/cli.ts examples/echo.yaha
```

파일 없이 실행하면 대화형 모드가 됩니다. 코드를 쓰고 빈 줄을 넣으면 실행하고, `:exit`로 끝냅니다. 앞에서 묶은 값과 함수는 계속 기억합니다. 대화형 모드에서 `야푸`는 항상 −1을 돌려줍니다.

```bash
node src/cli.ts
```

`pnpm link --global`을 실행해 두면 어디서든 `ura 파일.yaha`로 실행할 수 있습니다.

## 플레이그라운드

[usagi-lang.github.io/fp-usagi](https://usagi-lang.github.io/fp-usagi/)에서 코드를 고치고 바로 실행할 수 있습니다. `main`에 푸시하면 GitHub Actions가 테스트와 빌드를 거쳐 자동으로 다시 배포합니다.

- 문법 색, 예제 불러오기, 입력(`야푸`), 사전, 숫자·글 인코더를 갖췄습니다.
- `⌘↵`(Windows는 `Ctrl+↵`)로 실행합니다.
- **공유**를 누르면 코드가 담긴 링크가 만들어집니다.
- 프로그램은 별도 작업 스레드에서 돕니다. 5초가 지나거나 출력이 20만 글자를 넘으면 멈춥니다.

```bash
pnpm web
```

개발 서버를 띄웁니다(`http://localhost:5173`).

```bash
pnpm web:build
```

배포용 정적 파일을 `dist/`에 만듭니다. 배포 워크플로는 [.github/workflows/pages.yml](.github/workflows/pages.yml)에 있습니다.

## 둘러보기

**숫자.** `야하` 뒤에 붙은 `!`의 개수가 숫자입니다. 앞에 `이`를 하나 붙일 때마다 부호가 바뀝니다.

```
미이이야하 야하!!!
미이이야하 이야하!!!
```

→ `3`, `-3`

**변수.** `우`로 시작하고 `우`·`라`·`아`로만 된 말이 변수입니다. 변수는 글자 수로만 구분해서 `우라`, `우아`, `우우`는 모두 같은 변수입니다. `미야아아`로 값을 묶습니다.

```
미야아아 우라 야하!!!!!
미이이야하 우아
```

→ `5`

**계산.** 연산자를 앞에 씁니다. `푸릿`(+), `푸리릿`(−), `푸리리릿`(×), `푸리리리릿`(÷)입니다.

```
미이이야하 푸리리릿 야하!!! 푸릿 야하!! 야하!!!!
```

→ `18`

**조건.** `푸루`(같다), `푸루루`(작다), `푸루루루`(크다) 뒤에 두 값을 쓰면, 참일 때 그다음 문장 하나나 `하!` … `하?` 블록을 실행합니다. 비교 말을 이어 쓰면 OR가 되어서 `푸루 푸루루`는 "작거나 같다"입니다.

```
푸루 푸루루 야하!! 야하!!! 하!
  미이이야하 야하!
하?
```

→ `1`

**함수.** `우라-야하!` 다음에 이름(`하아!`, `하아아!` …)과 매개변수를 쓰고, 같은 이름에 `?`를 붙여(`하아?`) 닫습니다. 부를 때는 `하아-`, 값을 돌려줄 때는 `푸루야`를 씁니다. 함수 이름은 `아`의 개수로 구분합니다.

```
우라-야하! 하아! 우
푸루 우 야하 푸루야 야하!
푸루야 푸리리릿 우 하아- 푸리릿 우 야하!
하아?

미이이야하 하아- 야하!!!!!
```

→ `120`

## 함수형 기능

**함수를 값으로.** `-` 없이 `하아`라고만 쓰면 함수 자체를 가리킵니다. 변수에 담은 함수는 `우-`처럼 변수 뒤에 `-`를 붙여 부릅니다. 인자를 몇 개 읽을지는 함수의 매개변수 개수가 정합니다.

**이름 없는 함수.** `우라-야하!` 뒤에 이름 없이 매개변수를 쓰고 `하!` … `하?`로 본문을 감쌉니다. 값이 들어갈 수 있는 곳이면 어디든 쓸 수 있습니다.

**클로저.** 함수는 만들어질 때의 값을 기억합니다. 아래에서 `우`를 나중에 10으로 다시 묶어도, 함수는 만들어질 때의 3을 씁니다.

```
미야아아 우 야하!!!
미야아아 우라 우라-야하! 우우우 하! 푸루야 푸리리릿 우 우우우 하?
미야아아 우 야하!!!!!!!!!!
미이이야하 우라- 야하!!
```

→ `6`

**바뀌지 않는 값.** `미야아아`는 원래 값을 고치지 않고, 같은 이름을 새로 묶어 가립니다. 블록 안에서 묶은 값은 블록이 끝나면 사라집니다.

```
미야아아 우 야하!
푸루 야하 야하 하!
  미야아아 우 야하!!
  미이이야하 우
하?
미이이야하 우
```

→ `2`, `1`

함수만으로 목록을 만들고 `map`과 합을 적용하는 예는 [examples/list.yaha](examples/list.yaha)에 있습니다.

## 사전

| 말 | 기능 |
|---|---|
| `야하!!!` | 정수 (`!` 개수) |
| `이` | 부호 바꾸기 (숫자 앞에 붙임) |
| `우`, `우라`, `우라라`, … | 변수 (글자 수로 구분) |
| `미야아아` | 묶기 |
| `미이이야하` | 정수 출력 (뒤에 줄바꿈) |
| `미이이이야하` | 글자 출력 (유니코드 코드 포인트) |
| `야푸` | 입력 한 글자 읽기 |
| `푸릿` · `푸리릿` · `푸리리릿` · `푸리리리릿` | 더하기 · 빼기 · 곱하기 · 나누기 |
| `푸루` · `푸루루` · `푸루루루` | 같다 · 작다 · 크다 |
| `하!` … `하?` | 블록 |
| `우라-야하! 하아! 매개변수…` … `하아?` | 함수 선언 |
| `하아-` | 함수 호출 |
| `하아` | 함수 값 |
| `우-` | 변수에 담긴 함수 호출 |
| `우라-야하! 매개변수… 하!` … `하?` | 이름 없는 함수 |
| `푸루야` | 값 돌려주기 |
| `#` | 주석 |

## 명세

### 문장

프로그램, 함수 본문, 블록은 문장을 위에서부터 차례로 실행합니다.

| 문장 | 형태 |
|---|---|
| 출력 | `미이이야하 식`, `미이이이야하 식` |
| 묶기 | `미야아아 변수 식` |
| 조건 | `비교… 식 식` 다음에 문장 하나 또는 블록 |
| 돌려주기 | `푸루야 식` 또는 `푸루야` |
| 호출 · 계산 | `하아- …`, `우- …`, `푸릿 …` 등. 결과는 버립니다 |
| 블록 | `하! 문장… 하?` |
| 함수 선언 | `우라-야하! 하아! 변수… 문장… 하아?` |

### 식

| 식 | 형태 |
|---|---|
| 정수 | `이…야하!…` |
| 변수 | `우…` |
| 계산 | `푸릿 식 식` 등 |
| 호출 | `하아- 식…`, `우- 식…` (식 개수 = 매개변수 개수) |
| 함수 값 | `하아` |
| 이름 없는 함수 | `우라-야하! 변수… 하! 문장… 하?` |
| 입력 | `야푸` |

### 평가 규칙

| 항목 | 규칙 |
|---|---|
| 값 | 정수(크기 제한 없음), 함수 |
| 묶기 범위 | `미야아아`로 묶은 값은 그 블록의 나머지 부분에서만 보입니다 |
| 묶지 않은 변수 | 0 |
| 함수 이름 | 선언한 블록 안이면 선언보다 앞에서도 부를 수 있습니다. 같은 블록에 같은 이름을 두 번 선언하면 오류입니다 |
| 함수 환경 | 이름 있는 함수는 블록이 시작될 때의 값을, 이름 없는 함수는 만들어진 자리의 값을 기억합니다 |
| 돌려주기 | `푸루야`가 없거나 뒤에 식이 없으면 0 |
| 나눗셈 | 0 쪽으로 버립니다. `-7 ÷ 2 = -3` |
| 꼬리 호출 | `푸루야` 바로 뒤의 호출은 스택을 쓰지 않습니다 |
| 출력 | `미이이야하`는 정수 뒤에 줄바꿈을 붙이고, 함수는 이름을 출력합니다 |
| 입력 | `야푸`는 코드 포인트를 돌려주고, 입력이 끝나면 −1 |

### 오류

오류 메시지는 `하아? 하아?`로 시작하고, 위치를 함께 알려 줍니다.

```text
하아? 하아? (2줄 7칸) '안녕'... 우사기는 그런 말 안 해
하아? 하아? (2줄 7칸) '우-'... 함수가 아니라서 부를 수 없어
하아? 하아? (3줄 1칸) '하아?'(으)로 닫아야 하는데 '하아아?'가 나왔어
```

## 도구

`야하!!!!!!!!…`를 손으로 세기는 어렵습니다. 인코더가 대신 세어 줍니다.

```bash
node src/cli.ts num 72
```

72를 `푸리리릿 야하!!!!!!!! 야하!!!!!!!!!`(8 × 9)로 바꿔 줍니다. 큰 수는 a × b + r로 쪼개서 짧게 만듭니다.

```bash
printf '우라!\n' | node src/cli.ts encode
```

주어진 글을 출력하는 프로그램을 통째로 만들어 줍니다.
